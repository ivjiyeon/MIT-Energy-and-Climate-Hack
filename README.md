# PhaseFarm: can phase change materials beat insulation for hydroponic farms?

**MIT Climate Hackathon × COMSOL challenge:** *"Are there scenarios where phase change materials (PCMs) can reduce total cost compared with traditional insulation alone?"*

PhaseFarm is a free, browser-only web app. It simulates a hydroponic greenhouse, vertical farm or container farm, then compares the 20-year cost of three options:

| Option | What it means |
|---|---|
| Base | The building as is, without PCM |
| Hybrid PCM | Existing insulation with PCM panels |
| Full PCM | Upgraded insulation with PCM panels |

It answers "does PCM pay off here?", shows where it would (break-even PCM price, energy price, climate), and connects to COMSOL Multiphysics® for higher-fidelity physics.

## Quick start

```bash
cd site                          # this folder (the one containing this README)
python3 -m http.server 8000      # any static server works
# open http://localhost:8000
```

There's no build step, no install and no backend. To publish for free, drag this `site/` folder onto https://app.netlify.com/drop. Other options are in [docs/HOSTING.md](docs/HOSTING.md).

## Reproducing the results

The study in [docs/WHERE_PCM_WINS.md](docs/WHERE_PCM_WINS.md) is generated by a script. It needs [Node.js](https://nodejs.org) 18+ and no other installs.

```bash
cd site                                        # this folder
node tools/explore_levers.js                   # print the results tables (~2 s)
node tools/explore_levers.js > results.md      # or save them to a file
```

To change the assumptions, edit the top of `tools/explore_levers.js`:
- `DEFAULTS`: prices, tariffs, finance, PCM properties (same keys as the app's sidebar)
- `LEVERS`: the scenarios tested; add your own as `['Name', { key: value }]`
- `SITES`: which locations to run (any key from `CLIMATES` in `model.js`)

Paste the new tables into section 3 of `WHERE_PCM_WINS.md`, and check that the written conclusions in sections 4–5 still hold. The app's **Paths to a PCM win** section runs the same calculation for whatever scenario is selected, with no command line needed.

## What you can do

- **Compare costs:** life-cycle cost, upfront cost, payback, CO₂, HVAC energy cost per kg of crop and power-outage ride-through for all three options.
- **Strategy comparison benchmark:** [`strategy_comparison_data.csv`](./strategy_comparison_data.csv) stores the provided default metrics, hourly-comparison annual electricity use and cost, and annual savings deltas for Base, Hybrid, and Full PCM. The comparison table and Annual electricity cost by strategy chart load these values from the CSV. Annual savings & payback uses `annual_electricity_cost` and `capex` for its annual savings and cumulative payback calculations. The other scenario cards and charts remain calculated from the selected inputs.
- **See electricity savings and payback:** choose two strategies to compare annual electricity-cost differences and see when the investment's cumulative discounted savings break even.
- **Compare thermal performance:** the thermal chart compares any pair of Base, Hybrid PCM, and Full PCM monthly hourly mean indoor temperatures from `All_Three_Models_Hourly_Comparison.csv`. The default greenhouse is 19.2 m wide × 43.3 m long with a 5.3 m ridge height; the thermal model treats that height as rectangular and does not represent roof pitch or eave height.
- **Compare electricity use:** choose monthly or hourly averages for Base, Hybrid PCM, and Full PCM in `All_Three_Models_Hourly_Comparison.csv`. Monthly view averages all hourly records in each month; hourly view averages each hour-of-day across all dates in the selected month. Values are shown in kWh/hour and the chart does not apply electricity prices. The saved 2025 EIA retail-rate profiles in `electricity_data/` remain available to the model’s other cost calculations. Run `python3 electricity_data/build_profile.py` to generate the static browser profile; no API key or server is needed at runtime. The supplied rates are residential (RES), so Denver and Boston model costs use them as explicitly labeled proxies for commercial farm rates; other locations use configured fallback prices.
- **Outdoor temperatures:** the app automatically loads Open-Meteo hourly archive temperatures for the previous complete year and calculates a 24-hour average profile for each month and location. Built-in climate normals are used if the request fails.
- **Find break-even points:** heatmaps of PCM price × energy price, and of melt temperature × PCM quantity (the optimizer).
- **Sensitivity:** a tornado chart showing which assumption matters most.
- **Scan scenarios:** 11 cities × 3 farm types ranked by PCM savings and break-even PCM price.
- **COMSOL:** export parameters and weather to COMSOL, import COMSOL temperatures to calibrate the model, or import COMSOL heating/cooling loads to drive the costs.
- **Customize:** add locations, PCM products, crops, facility types, custom cost items (grants, labour…), team notes and saved scenarios. Export everything as one `custom.json`.
- **Paths to a PCM win:** for your scenario, tests each real-world lever (fan-assisted panels, cheaper PCM, tariffs, off-grid power, outage value, carbon price) and combinations, each with an optimized PCM design.
- **Share:** the URL encodes your inputs. You can also export results as CSV.

## Headline findings

- **Passive PCM panels (the defaults) lose almost everywhere.** At ~$5/kg they beat insulation in 0 of 33 scenarios. The physics reason: in still air the panels cycle only **9–14 %** of their storage capacity on an average day, because heat transfer is the bottleneck.
- **Fan-assisted thin panels flip high-swing greenhouses**, even after paying for fan energy and ducts. **Nairobi +$41k** (5.7 % of 20-yr cost); Denver and Phoenix about break-even.
- **Clear wins appear when** power is expensive or off-grid (**Denver +$56k**), crop protection during outages is valued (**Boston +$84k**), or PCM costs ≤ $1.5–2.5/kg.
- **No path to a win:** humid tropics, mild maritime climates and LED-heated vertical farms.
- **The deciding unknown:** panel heat transfer vs fan power. That's exactly what a COMSOL airflow model can settle.

So the answer is **"yes, under specific conditions"**, and the app shows which. Try the ★ quick scenarios. Full results: [docs/WHERE_PCM_WINS.md](docs/WHERE_PCM_WINS.md). Plan: [docs/NEXT_STEPS.md](docs/NEXT_STEPS.md). History: [docs/PROJECT_LOG.md](docs/PROJECT_LOG.md).

## Caveats

This is a screening tool. The model is a single-zone lumped model with representative days, it ignores humidity loads, and its default prices are indicative. Use it to find promising scenarios, then confirm them with COMSOL and real quotes.
